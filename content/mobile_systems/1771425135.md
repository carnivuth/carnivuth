GPS is a positioning system that exploits dedicated hardware (*e.g. satellites*) for improved performance in localization capabilities

The concept is to use [lateration](/1771425122#lateration) in combination with [toa](/1771425122) using satellites with known positions

![](/1794065310.png)

GPS satellites needs to have a perfect synchronized clock, $1_{\mu s}$ can achieve an error of around 300 meters

## Differential gps

To reduce the error range of GPS a base station with a fixed position is used to correct the error in the satellites measures
